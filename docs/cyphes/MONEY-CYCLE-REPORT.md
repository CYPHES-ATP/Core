# CASH money cycle: evidence

Generated by `cyphes-wallet/tests/money_cycle.rs` (the full run, with the default
100-confirmation coinbase policy). Every block below was mined with a real BeamHash III
solution on a local regtest node that validates proof of work. Reproduce with:

```sh
cargo build -p zebrad --features internal-miner
cargo test -p cyphes-wallet --test money_cycle -- --ignored --nocapture
```

Addresses and transaction IDs differ on every run: each run creates fresh wallets.

## 4. Reorganisation

Node 2 syncs node 1's chain to height 112; then the nodes are separated.
- PASS on node 1's branch Bob receives 777 CASH in block 113 (`c77328f19b9906352a33295c8ef9cf7372238120954554770b8d95b7bf2aef57`)
- PASS node 2 restarts with its synced chain intact (height 112)
Node 2, alone, mines 3 blocks to height 115: a longer branch without the payment.
- PASS node 1 restarts with its branch intact (height 113)
- PASS node 1 rejects `458db32e4a1cd1227a3e2e16bd4b4c27af2145734991d753a4c47034c54e04ac`, whose anchor is only on node 2's branch: {"code":-25,"message":"failed to validate tx: WtxId(\"private\"), error: transaction did not pass consensus validation: could not contextually validate transaction on best chain: unknown Ironwood anchor: Root(\"f99e6b07fdebc0ed66464d55514aa627c06e8d129bde4049326dafe04b1e5827\"),\nNone, index in block: None, transaction::Hash(\"458db32e4a1cd1227a3e2e16bd4b4c27af2145734991d753a4c47034c54e04ac\")"}
- PASS the rejection names the unknown Ironwood anchor
- PASS node 1 reorganises to node 2's longer branch (height 115)
- PASS Bob's wallet follows the reorganisation: the orphaned payment is no longer confirmed; spendable is back to 1500.00000000 CASH
The orphaned 777 CASH now shows as unconfirmed (pending 777.00000000 CASH): the transaction is still valid on the new chain, so the wallet waits to see whether it confirms again.
After the reorganisation the orphaned payment is not in node 1's mempool; Alice's wallet broadcasts it again.
The transaction rejected for its unknown anchor has since confirmed, retried by the node, on the winning chain, where its anchor exists.
- PASS the orphaned payment confirms on the winning chain
- PASS Bob's balance matches the winning chain: 2265.99990000 CASH (2265.99990000 spendable, 0.00000000 pending)
- PASS Alice's balance matches the winning chain: 733.99980000 CASH (722.99980000 spendable, 11.00000000 pending)
